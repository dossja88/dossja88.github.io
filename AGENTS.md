# Public Project Media Hub — repository publishing rules

**Repository:** `dossja88/dossja88.github.io` (PUBLIC). GitHub Pages static website, not a private upload or source-storage service. This is an intentionally shared **public output surface** for multiple projects. Each underlying project keeps its own instructions, handoff, identities and independently authorized private storage; this file grants **no** authority over those projects.

## Guardrails

- **PUBLIC MEANS PUBLIC:** every committed page, script, audio file, image, comment and history entry is accessible to others. Do not commit unreleased source, user/client files, saleable original masters, private media-review drafts, account email addresses, API keys, tokens, cookies, credentials, personally identifying information, Google Drive file IDs/links, or raw viewer memory/state. A public link is never a private review link.
- **Item-by-item release:** Only upload/publish an exact artifact when its originating project's responsible approval, source rights/license/attribution, privacy, QA, content and intended audience are established. General permission to operate or rebrand this site does **not** authorize release of arbitrary project output, media or protected material. Keep publication and owner's private-review upload entirely separate.
- **Existing app:** The root `index.html` is currently an informational homepage for **Sleep Channel Private Reviews**, a single-owner `drive.file` Google OAuth-related review tool. Keep this name and accurate app description visible, and keep root `privacy.html` and `terms.html` publicly accessible through stable URLs. This project's homepage/links may be part of Google OAuth app branding. Do not change the app name, OAuth description, privacy/terms paths, user-data claims, or Google console app settings without separately verifying the OAuth configuration and applicable approval. `googlef455cdc484315901.html` and `.nojekyll` must remain untouched unless independently authorized.
- **Shared public index:** `projects/index.html` is only a static **directory for approved public outputs**, initially containing no publicly released videos or audio. Future project content should use approved, collision-free directory names and link targets. Do not make pages that imply a project, customer, product or result is public/finished without the responsible project's confirmation.
- **Clanker exception:** The existing `dossja88/clanker-live-chat` GitHub Pages Brain Lab/stage remains on its current origin/path. Do not migrate, iframe, mirror, relink as a production host or make its source repository private without verifying its same-origin `BroadcastChannel`, OAuth/Twitch and actual browser dependencies and obtaining applicable deployment/security approval. A public static HTML/JS client exposes its embedded source code.
- **No paid infrastructure:** No subscription, extra domain purchase, paid hosts, metered media transfer, Actions pipeline, background automation or credential expansion under this site without separate approval. Default to static HTML/CSS, zero trackers, no external scripts or network APIs.
- **Safe changes:** Before modifications, inspect live `main`, current files, open PR/writer state and relevant project handoff once. Preserve non-target files; avoid destructive rewrites. For approved edits, verify exact GitHub readback, relative links, and core content invariants. Independently verify browser Pages delivery when an appropriate tool is available. Do not claim a live URL has been smoke-tested based only on a GitHub commit; stop and report an unverifiable host state.
- **Minimal reporting:** identify what changed, its commit, whether live serving was tested, what remains private, added cost and next user approval/technical gate. No new client, income or distribution claims merely from publishing a hub page.

Private reviews are routed through each project's already approved **Restricted Google Drive** workflow, not through this public GitHub Pages repository. Content can appear on this site **only after separate, explicit public release authorization**.
